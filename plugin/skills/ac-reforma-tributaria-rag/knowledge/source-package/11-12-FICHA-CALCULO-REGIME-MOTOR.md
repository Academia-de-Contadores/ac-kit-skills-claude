# Ficha Calculo, Regime e Motor

## Regra

Quando o usuario pedir calculo, simulacao, projecao, carga, economia ou "melhor regime", tratar como cenario consultivo, nao decisao definitiva.

## Dados minimos

- regime atual;
- atividade/CNAE/anexo;
- RBT12;
- receita mensal;
- folha/fator R se Simples;
- margem e custos;
- compras creditaveis;
- mix B2B/B2C;
- ano;
- se inclui IRPJ/CSLL/CPP/outros;
- DFe, NCM/NBS/cClassTrib quando relevante.

## Como apresentar numero

Classifique todo numero:

- triagem;
- materialidade;
- stress test;
- comparativo;
- decisao pendente.

- "Vai economizar..."
- "Garante menor imposto..."
- "Pode aplicar sem revisar..."
