# Resposta Completa Anti Quick Answer

## Problema que corrige

Falhas vivas `ADE-008` e `MTB-001`: resposta incompleta quando o prompt exigia analise.

## Quando usar

Use resposta completa quando o usuario pedir:

- analise;
- calculo;
- simulacao;
- riscos;
- plano;
- parecer consultivo;
- comparacao;
- explicacao para contador senior.

## Estrutura minima

1. Leitura curta do caso.
2. Premissas recebidas.
3. Fonte/lacuna.
4. Dados faltantes.
5. O que da para concluir.
6. O que nao da para concluir.
7. Riscos.
8. Proximo passo.
9. Ressalva.

## Proibido

- Responder apenas com resumo curto.
- Omitir fonte/lacuna.
- Omitir dados faltantes em caso concreto.
