# Onboarding de cliente, documentos, notas e atas

Versão 0.2.1 · 07/10/2026.

## 1. Contratação confirmada → onboarding

Não esperar todos os documentos para registrar a contratação.

1. Procurar o cliente (identificador, depois nome + contato). Se houver negociação no Comercial, atualizar o desfecho preservando o histórico.
2. **Cadastro mínimo no CRM** com o que foi confirmado: nome, identificador, status, início, contatos, serviços. O que não foi informado fica vazio e listado como pendência.
3. **Ficha** em Clientes Mensais: acordos do alinhamento, particularidades, contatos preferidos. Preencher a relação com o CRM se existir e estiver confirmada.
4. **Onboarding**: se existir um POP de onboarding no Time, seguir as etapas dele; senão, usar o checklist que a usuária fornecer. Criar tarefas para as próximas etapas com os responsáveis do POP; prazo só se o POP ou a usuária definir, senão [A DEFINIR]. Para cada item: recebido / faltando / não se aplica / a confirmar, com responsável interno.
5. Honorário só com valor informado; senão, pendência.
6. Departamentos: só os do escopo contratado. Cliente sem DP não ganha controle de DP.
7. Se pedido, preparar mensagem ao cliente pedindo **apenas o que falta**, com os prazos combinados. Não enviar.
8. Devolver links por etapa: negociação, CRM, ficha, onboarding, departamentos.

## 2. Documentos recebidos

1. Comparar arquivos com o checklist do onboarding. Dizer se leu o conteúdo ou viu só o nome.
2. Separar: recebido e conferido / recebido não legível ou incompleto / faltando.
3. Extrair dados citando o arquivo de origem.
4. **Divergência** com o cadastro (telefone, endereço, sócios): mostrar as duas versões e não substituir sem decisão.
5. Arquivos ficam no repositório do escritório (Drive, OneDrive, pasta); o Notion guarda link e situação. Mover arquivos só com acesso e pedido específicos.

## 3. Notas e atas

| Entrada | Destino |
|---|---|
| Nota sobre cliente | Ficha do cliente (corpo/histórico), com data |
| Ata de reunião de projeto | Página do projeto ou área de reuniões existente |
| Reunião semanal do time | Time → Reunião (modelo de ata) |
| Aprendizado | Estudos |
| Ideia de conteúdo | Marketing, controle apropriado |
| Ideia de serviço | P&D |
| Nota sem contexto suficiente | Perguntar a finalidade antes de gravar |

**Formato da nota:** data, participantes, fatos, decisões, ações combinadas (quem, o quê, até quando).

**Ações:** só o que foi combinado vira tarefa. Ideia, possibilidade ou “talvez” fica na nota. Antes de criar tarefa, procurar uma existente para a mesma ação e atualizá-la. Não inventar responsável nem prazo; se faltar, deixar a ação na nota e perguntar.

**Ata repetida:** se a mesma nota for enviada de novo, localizar a anterior e as tarefas ligadas antes de criar qualquer coisa.
