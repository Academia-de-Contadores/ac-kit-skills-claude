Instala o kit da Academia neste aplicativo: https://github.com/Academia-de-Contadores/ac-kit-skills-claude . Leia INSTALL.md, identifique se está no Codex ou no Claude e execute a rota correspondente. Preserve minhas skills existentes e confira as dez skills ao terminar.

Não procure o repositório pela busca do GitHub. Se não conseguir abrir a página, leia https://raw.githubusercontent.com/Academia-de-Contadores/ac-kit-skills-claude/main/INSTALL.md . Não confunda uma falha de rede com repositório privado. Não peça senha ou token para baixar este kit público. No Claude, use o instalador nativo ou o catálogo, com importação do ZIP como alternativa. No Codex local, instale no diretório de skills do usuário. Só declare instalado com evidência do destino.
